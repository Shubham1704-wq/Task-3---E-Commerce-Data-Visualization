# Task 3: E-Commerce Data Visualization

## Project Overview
This project focuses on presenting e-commerce sales information through clear and meaningful visualizations. It uses the cleaned and analyzed data from the previous tasks to communicate business patterns and findings.

## Objectives
- Create visualizations that explain sales performance.
- Compare revenue across product categories.
- Display monthly sales trends.
- Show the distribution of revenue across categories.
- Design a dashboard mockup that brings important information together.
- Provide short interpretations of the visualizations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Visualizations
### 1. Bar Chart
Used to compare revenue across product categories.

### 2. Line Chart
Used to display sales trends over time, such as monthly sales.

### 3. Pie Chart
Used to show the proportional contribution of categories to revenue.

### 4. Dashboard Mockup
A dashboard-style layout combining important KPIs and visual insights in one place.

## Workflow
1. Load the required cleaned data.
2. Prepare the category and time-based summaries.
3. Create the bar chart, line chart, and pie chart.
4. Design the dashboard mockup.
5. Add short interpretations to explain the charts.
6. Save the visual outputs for presentation.

## Expected Deliverables
- Visualization notebook
- Bar chart
- Line chart
- Pie chart
- Dashboard mockup
- Short interpretations of the visualizations

## Outcome
This task presents the results of the e-commerce analysis in a visual format, making sales patterns and business findings easier to understand.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Provide the required cleaned dataset.
3. Run the notebook cells in order.
